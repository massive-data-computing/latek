# LaTeK: A Large-scale Text-to-KG Benchmark Generation Framework

## Overview

LaTeK is a large-scale benchmark generation framework for evaluating Long Text-to-Knowledge Graph (KG) generation approaches.

The benchmark dataset is constructed from knowledge graphs extracted from Wikipedia articles using KGGen (https://github.com/stair-lab/kg-gen). Based on these knowledge graphs, LaTeK generates textual descriptions by considering two important factors: (1) Sentence Structure Complexity and (2) Entity/Relation Identification Level across Documents.

The resulting benchmark dataset consists of textual inputs and their corresponding ground-truth knowledge graphs.

## Dataset Structure

The dataset is provided in JSON format. Each data instance consists of four types of textual input collections and their corresponding ground-truth knowledge graphs.

The JSON structure contains the following fields:

- **type1, type2, type3, type4:** Four types of textual input collections. Each field contains a list of textual inputs used in the benchmark.
  - type1: Simple Text
  - type2: Rephrased Simple Text
  - type3: Complex Text
  - type4: Rephrased Complex Text
- **answers:** Ground-truth KGs associated with the textual inputs. Each answer contains the following fields:
  - `gid`: A unique identifier for the ground-truth KG.
  - `entity_id`: The identifier of the entity associated with the ground-truth KG.
  - `entity_name`: The entity name corresponding to the title of its Wikipedia article.
  - `triple_set`: A set of knowledge graph triples associated with the entity.

### Example

```json
{
  "type1": [...],
  "type2": [...],
  "type3": [...],
  "type4": [...],
  "answers": [
    {
      "gid": 0,
      "entity_id": 0,
      "entity_name": "Chatou",
      "triple_set": [
        ...
      ]
    },
    {
      "gid": 1,
      "entity_id": 0,
      "entity_name": "Chatou",
      "triple_set": [
        ...
      ]
    },
    ...
  ]
}
```

## Data Source and Attribution

The knowledge graphs are extracted from Wikipedia articles using KGGen and further processed by LaTeK. The corresponding textual descriptions are then generated by an LLM based on these processed knowledge graphs.

- **Source:** Wikipedia articles (https://www.wikipedia.org/)
- **Source Content License:** Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)
- **License URL:** https://creativecommons.org/licenses/by-sa/4.0/

The `entity_name` field identifies the corresponding Wikipedia article title and can be used to locate the original source article.
